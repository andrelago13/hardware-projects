# Plant Monitor

This project is meant to install multiple sensors like humidity or temperature sensors in plant pots and periodically report them to an external API so that users can be alerted if they need to water their plants or take other cautionary actions.

In this project we'll create the code for all 3 components, the hardware sensors, backend API and a client where we can view charts, etc.

Hardware components:

- WiFi ESP8266 (ESP12E) - CH340 NodeMCU V3 Lua 
- DHT22 Temperature and Humidity sensor
- Keyestudio KS0049 soil humidity sensor
- 3.7V 1100mAh Li-Po battery
